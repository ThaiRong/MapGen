# MapGen

Локальный офлайн-генератор карт для настольных ролевых игр (НРИ).
Работает полностью на машине пользователя: без CDN, внешних шрифтов и сетевых запросов в runtime.

Текущее состояние — **итерация 1**: каркас приложения, дерево карт, ручное нанесение локаций,
навигация между картами, сохранение/загрузка проекта, undo/redo.
Подробности и границы итераций — в [docs/PROJECT_BRIEF.md](docs/PROJECT_BRIEF.md) и [PROJECT_STATE.md](PROJECT_STATE.md).

## Стек

- Tauri 2 (Rust backend)
- React 18 + TypeScript
- Vite 6
- Canvas 2D
- Zustand

Целевая ОС — Windows.

## Требования

- [Node.js](https://nodejs.org/) LTS (проверено на 26.x)
- [Rust](https://rustup.rs/) stable (проверено на 1.100)
- **Windows:** MSVC Build Tools (рабочая нагрузка «Разработка классических приложений на C++» /
  «C++ build tools») — можно поставить через
  `winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"`

## Установка

```bash
npm install
```

## Запуск (режим разработки)

```bash
npm run tauri dev
```

Собирает Rust-бэкенд, поднимает Vite dev server и открывает окно приложения.

### Windows: замечание об антивирусе

На машинах с корпоративным Kaspersky возможна блокировка запуска свежесобранных exe
внутри папки проекта (os error 32 / «Отказано в доступе»). Обходные пути:

- запускать dev-сборку с `CARGO_TARGET_DIR` вне папки проекта — готовые обёртки:
  `scripts\tauri-dev.bat` (dev-режим) и `scripts\cargo-vs.bat` (произвольные cargo-команды,
  например `scripts\cargo-vs.bat check --manifest-path src-tauri\Cargo.toml`);
- либо добавить папку `src-tauri\target` (и `%LOCALAPPDATA%\Temp\mapgen-target`) в исключения антивируса.

## Как пользоваться

- **Дерево карт** (слева) — вложенная иерархия карт; клик открывает, двойной клик или ✎ переименовывает,
  ✕ удаляет с подтверждением (удаление каскадное, отменяется Ctrl+Z).
- **Холст** (центр) — колесо мыши масштаб, средняя кнопка или пробел + перетаскивание — панорама.
- **«Добавить локацию»** — клик по холсту ставит маркер и создаёт дочернюю карту;
  двойной клик по маркеру входит внутрь.
- **Рисование (итерация 2)** — инструменты в тулбаре: **Точка**, **Линия**,
  **Область**, **Подпись**. Линия и область рисуются кликами по вершинам с
  предпросмотром; завершение — Enter, двойной клик (область также замыкается
  кликом по первой вершине), отмена — Esc. Подпись вводится в поле на холсте.
  **Удаление** — клик по объекту; Delete удаляет выбранный. Перемещение —
  перетаскивание выбранного объекта (одна запись в журнале).
  Инструменты рисования используют тип, выбранный в панели легенды.
- **Легенда** (левый нижний угол) — нейтральные типы, задающие стиль
  примитивов: цвет, прозрачность, толщину и стиль линии. По умолчанию —
  4 базовых типа (Точка, Линия, Область, Подпись); «+ Тип» создаёт свой
  (форма — по текущему инструменту). Категории придумывает пользователь.
  Используемый тип удалить нельзя; базовый — если это сломает покрытие формы.
  Видимость типа и отдельного примитива (в инспекторе) влияет на отрисовку.
- **Инспектор примитива** — имя, тип только совместимой формы, заметка,
  координаты/число точек, видимость, блокировка; у подписи — текст и размер.
- **Удаление маркера** — безопасное: связанная карта остаётся в дереве, а маркер переносится
  в архив. Кнопка **«Архив»** в тулбаре открывает список удалённых маркеров:
  восстановление возвращает маркер на прежние координаты со связью на прежнюю карту.
  Если целевая или исходная карта удалена, запись помечается с понятной причиной.
- **Журнал изменений** — кнопка **«История»** открывает панель в стиле History
  в Photoshop: список действий с временем и понятными описаниями, текущая запись
  выделена. Клик по записи возвращает проект к этому состоянию, клик по более новой —
  идёт вперёд, пока ветвь не перезаписана. Если вы вернулись назад и начинаете новое
  действие, приложение спросит подтверждение перезаписи отменённой ветви.
  Записи об удалении маркеров позволяют восстановить маркер прямо из журнала.
  Хранится до 100 последних действий; журнал сохраняется в файле проекта.
- **Хлебные крошки** (сверху) — переход по иерархии, кнопка «Наверх».
- **Инспектор** (справа) — свойства карты (в т.ч. опциональный масштаб) или выбранного маркера.
- **Сохранение** — файл `.mapkg` (JSON); автосохранение — во внутреннее хранилище приложения.
- **Ctrl+Z / Ctrl+Y** — отмена/повтор.

## Структура проекта

```
src/core/        модель данных, мутации, дерево карт, undo/redo
src/storage/     слой хранения (интерфейс + JSON + Tauri-реализация)
src/state/       Zustand-store приложения
src/components/  UI: дерево, холст, инспектор, крошки, тулбар, статус-бар
src-tauri/       Rust: команды сохранения/загрузки файлов, конфиг Tauri
scripts/         обёртки для Windows (среда MSVC, target вне папки проекта), иконки, смоук-тест
docs/            бриф продукта и итераций
```

## Принципы

- Сеттинг-агностичное ядро: только карта, точка-маркер, подпись и ссылка на другую карту.
  Никаких зашитых «таверн» и «гоблинов».
- Формат `.mapkg` — пока чистый JSON; слой хранения отделён, чтобы позже перейти на
  JSON + бинарные чанки + LZ4 без переписывания вызывающего кода.
- Место для будущего адаптера локальной LLM (Ollama) заложено архитектурно, интеграции нет.
