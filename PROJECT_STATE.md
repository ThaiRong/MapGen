## Сейчас делаем
Итерация 3 (детерминированная процедурная генерация) реализована и проверена:
- ядро: seeded PRNG (mulberry32 + FNV-1a хэш), value noise + fBm,
  поля высот/влажности/температуры, marching squares + Дуглаc–Пекер;
  generate(spec) — чистая функция, без Math.random, с лимитами
  (сетка ≤160, областей ≤96, линий ≤160, точек ≤400, вершин ≤400);
- примитивы получили origin ('manual'|'generated') и generationId;
  map.generation = { spec, generationId, appliedAt }; миграция старых
  файлов: origin='manual', спека без map.generation открывается;
- панель «Генерация» (постоянно видимая, третья колонка) с живым
  предпросмотром (debounce 150 мс, пониженное разрешение, токен отмены),
  областью генерации (вся карта / видимая / рамкой на холсте), выбором
  типов легенды, зерном и кнопками «Применить» / «Перегенерировать»;
- применение — одна запись журнала (map.generated); перегенерация
  заменяет только origin='generated' текущего поколения и незаблокированные;
  ручные и locked примитивы не трогаются; подтверждение с числом замен.

Проверено: tsc, vite build, смоук-тест 150/150 (детерминизм, лимиты,
защита правок, миграция, идентичность геометрии после сохранения/загрузки).
Ждём следующую команду.

Примечание: на машине разработчика корпоративный Kaspersky блокирует
запуск свежесобранных exe внутри `C:\Users\WinBug\MapGen` (os error 32).
Обход: собирать с `CARGO_TARGET_DIR=%LOCALAPPDATA%\Temp\mapgen-target`
(см. scripts/tauri-dev.bat и scripts/cargo-vs.bat).
