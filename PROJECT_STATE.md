## Сейчас делаем
Итерация 1 завершена и проверена (tsc, vite build, cargo check, смоук-тест
ядра 68/68, запуск `npm run tauri dev` — окно открывается).

Подшаг 1.5.1 — безопасное удаление и восстановление маркеров — реализован:
удалённый маркер хранится в архиве (`Project.markerArchive`), восстанавливается
из диалога «Архив» на прежние координаты со связью на прежнюю карту;
удаление и восстановление проходят через историю отмен.

Подшаг 1.5.2 — журнал изменений в стиле History в Photoshop — реализован:
записи с типом операции, описанием, временем и снимком состояния
(`HistoryEntry` в core/history.ts, лимит 100 записей); панель «История»
(кнопка в тулбаре) с переходом по клику, кнопками Отменить/Вернуть и
восстановлением удалённых маркеров из записей; переход назад + новое
действие спрашивает подтверждение перезаписи ветви; журнал сохраняется
в .mapkg (толерантная загрузка: повреждённая история не ломает проект).
Ctrl+Z / Ctrl+Y двигают ту же позицию журнала. Ждём следующую команду.

Примечание: на машине разработчика корпоративный Kaspersky блокирует
запуск свежесобранных exe внутри `C:\Users\WinBug\MapGen` (os error 32).
Обход: собирать с `CARGO_TARGET_DIR=%LOCALAPPDATA%\Temp\mapgen-target`
(см. scripts/tauri-dev.bat и scripts/cargo-vs.bat).
