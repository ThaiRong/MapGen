## Сейчас делаем
Итерация 4 (генерация внутренних карт локаций по архетипу) реализована:
- контракты: StructureSpec/Result, MapGeneration — union
  { kind: 'terrain' | 'structure' }, MapNode.createdByGeneration,
  origin у маркеров-локаций; миграция kind-less → terrain;
- шесть сеттинг-агностичных архетипов (Ячеистая/Линейная/Радиальная/
  Кластерная/Открытая/Смешанная) в src/core/generation/structure/
  (rng — тот же PRNG итерации 3, partition, archetypes, generateStructure);
  деривация зерна deriveSeed(зерно родителя, id маркера);
- applyStructureToMap: одна транзакция — примитивы + вложенные маркеры
  с пустыми дочерними картами (createdByGeneration); перегенерация удаляет
  пустые вложенные карты и сохраняет карты с ручной работой; подтверждение
  с тремя числами (примитивы / карты удалить / карты сохранить);
- панель генерации с явными вкладками «Местность»/«Локация»; кнопка
  «Сгенерировать локация» в инспекторе маркера открывает дочернюю карту
  и предзаполняет зерно деривацией; предпросмотр с вложенными точками.

Проверено: tsc, vite build, cargo check, смоук-тест 193/193 (детерминизм,
валидность геометрии всех архетипов, деривация зерна, вложенность без
дубликатов, защита manual/locked, undo/redo с картами, миграции).
Ждём следующую команду.

Примечание: на машине разработчика корпоративный Kaspersky блокирует
запуск свежесобранных exe внутри `C:\Users\WinBug\MapGen` (os error 32).
Обход: собирать с `CARGO_TARGET_DIR=%LOCALAPPDATA%\Temp\mapgen-target`
(см. scripts/tauri-dev.bat и scripts/cargo-vs.bat).
