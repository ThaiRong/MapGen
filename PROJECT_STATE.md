## Последняя завершённая

Итерация 8 (окно игрока), 2026-11-28. Итог: второе окно Tauri
(toggle_player_window, тот же фронтенд в режиме ?player=1, рендер
Canvas 2D); мастер отправляет событие player:feed с проекцией из
projectForPlayer — фильтрация в основном процессе, скрытое не
сериализуется вовсе (геометрия, имена, заметки). Окно игрока — только
просмотр: свой pan/zoom, «следовать за камерой мастера», счётчик
видимых объектов, фильтруемая легенда (только типы с видимыми
объектами); инструментов, дерева, инспектора и заметок нет. Флаги
«показывать игрокам» в инспекторах маркера и примитива (записи
журнала entity.playerVisible), скрытые от игрока объекты помечены на
холсте мастера красным пунктирным кольцом. Синхронизация изменений
карты/тумана/флагов с троттлингом 200 мс; закрытие окна игрока не
влияет на проект. Проверки: tsc, vite build, cargo check, смоук-тест
277/277 (+4: флаг маркера в проекции, включение/выключение, дефолт,
отсутствие служебных данных в проекции).

Итерация 7 (туман войны), 2026-11-28. Итог: три независимые маски на
карту (ландшафт/топография/интерактивные) с XOR-семантикой на
разреженных тайлах 64×64 (src/core/fog.ts) — «скрыть всё»/«раскрыть
всё» O(1), инверсия переключением флага; сериализация в .mapkg,
миграция (нет fog = всё раскрыто), битые маски безопасны. Инструмент
«Туман»: кисть с радиусом, режим раскрыть/скрыть, чекбоксы категорий,
Alt — обратный режим; один штрих = одна запись журнала (fog.changed,
undo работает). Семантическая операция: клик по маркеру/примитиву —
туман над сущностью целиком. Массовые операции (раскрыть/скрыть всё,
инвертировать) с подтверждением и точными числами тайлов. Оверлей
мастера: скрытое показано деликатно, отключается. Проекция для игрока
(src/core/projection.ts): видимость = не скрыто туманом категории И
playerVisible !== false; скрытые сущности не попадают в проекцию
вообще (ни геометрия, ни имена, ни заметки) — база для окна игрока
итерации 8. Поля playerVisible у примитивов и маркеров с миграцией.
Проверки: tsc, vite build, cargo check, смоук-тест 273/273 (+30:
XOR-семантика, независимость категорий, маска полигона, сериализация,
миграция, undo, проекция — скрытое не попадает, флаги, заметки не
передаются, вложенные карты).

Итерация 6 (локальная модель: текст → structured spec), 2026-11-28.
Итог: изолированный ModelAdapter (src/core/model/): интерфейс +
Ollama-реализация (только 127.0.0.1/localhost, fetch инъецируем для
тестов, таймаут 30 с), валидация/санитизация вывода по контрактам спек
итераций 3–4 (диапазоны, архетип, отбраковка мусора с предупреждениями,
не-JSON отклоняется). Блок «Модель» в панели генерации: включение
(выключена по умолчанию), адрес, выбор модели, проверка соединения со
статусом; настройки в localStorage. Блок «Описание» в обеих вкладках:
распознавание → предпросмотр распознанных параметров и предупреждений →
явное «Подставить в форму»; зерно остаётся явным; любые ошибки —
понятный статус и бесшовный возврат к ручной форме. Генераторы от
модели не зависят (греп CLEAN). Проверки: tsc, vite build, cargo check,
смоук-тест 243/243 (+17: санитизация вывода, фолбэк адаптера при
недоступности/HTTP-ошибках/не-JSON, только локальный хост,
детерминизм распознанного spec).

## Заметки

- Ядро сеттинг-агностично, пресеты и словари пусты по умолчанию.
- Ручная работа (origin='manual', locked=true) защищена во всех генерациях.
- Окно игрока (итерация 8) получит только отфильтрованную проекцию, скрытые данные не передаются.
- На машине разработчика корпоративный Kaspersky блокирует запуск свежесобранных exe
  внутри папки проекта (os error 32). Обход: `CARGO_TARGET_DIR=%LOCALAPPDATA%\Temp\mapgen-target`
  (scripts/tauri-dev.bat, scripts/cargo-vs.bat).
