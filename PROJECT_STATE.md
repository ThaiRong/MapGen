## Сейчас делаем
Итерация 2 (ручной редактор примитивов + легенда) реализована и проверена:
- модель: Primitive (point/line/area/label) в MapNode.primitives, LegendType
  в Project.legend (4 нейтральных базовых типа «Базовые»);
- инструменты: выбор/перемещение, точка, линия, область, подпись (inline-ввод,
  без prompt), удаление; черновики с предпросмотром, Enter/Esc/двойной клик,
  замыкание области кликом по первой вершине;
- hit-testing с приоритетом маркеров и учётом зума; перетаскивание — одна запись
  журнала на перетаскивание;
- инспектор примитива (имя, тип только совместимой формы, заметка, visible,
  locked, текст и fontSize подписи) и панель легенды (создание/правка типов,
  видимость, правила удаления: используемые нельзя, базовые — если ломают
  покрытие формы);
- история: primitive.* и legend.* записи, restoreInfo для удалённых примитивов
  с кнопкой восстановления в панели «История»;
- миграция v1: нет legend → 4 базовых типа, нет primitives → []; битый typeId
  → фолбэк на тип формы, битая геометрия → отбраковка без краха;
- маркеры, навигация, архив, журнал из итераций 1/1.5 не сломаны.

Проверено: tsc, vite build, cargo check, смоук-тест 107/107, tauri dev
(окно открывается). Ждём следующую команду.

Примечание: на машине разработчика корпоративный Kaspersky блокирует
запуск свежесобранных exe внутри `C:\Users\WinBug\MapGen` (os error 32).
Обход: собирать с `CARGO_TARGET_DIR=%LOCALAPPDATA%\Temp\mapgen-target`
(см. scripts/tauri-dev.bat и scripts/cargo-vs.bat).
